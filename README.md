# NEXAR HUB OPTIMIZER

Site oficial e central de downloads do **NEXAR HUB OPTIMIZER v1.0 Beta**.

O NEXAR é um aplicativo nativo para Windows 10/11 x64 que reúne CPU Guard, RAM Cleaner, NEXAR HDD Engine, Discord Lite, painel de segundo plano e o perfil NEXAR Boost Gaming.

## Downloads

Use somente os arquivos publicados em [Releases](https://github.com/luidcorporation-ofc/nexar-hub-optimizer/releases) e compare o SHA-256 com `CHECKSUMS_SHA256.txt` antes de executar.

- Instalador com desinstalador próprio
- Versão portátil
- Documentação e checksums

## Limites transparentes

O aplicativo não cria processadores virtuais, não transforma HDD em SSD, não inventa memória RAM e não promete um consumo fixo para o Discord. Os resultados dependem do computador e da carga atual.
